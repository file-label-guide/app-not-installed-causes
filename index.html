Android install error

"App not installed": what the message is telling you

The error means Android rejected the APK. The words shown beneath or beside it say why. Keep the message on screen and read it before you remove anything or change a setting.

The most common one

Why a package conflict happens

Android identifies an app by its package name and its signing certificate. An update can replace an installed app only when both match. If the name matches and the certificate does not, Android blocks the replacement.

  1. Open Settings, then Apps, and find the existing installation named in the error.
  2. Confirm it is the conflicting package. Do not remove an unrelated app with a similar icon.
  3. Save any local settings or files you need. Uninstalling can remove them.
  4. Remove the confirmed installation, then install the current APK.

If the package installs and the app then will not open, closes, or rejects a key, the fault is in a different layer. For those, start from the symptom.

Two things to leave alone

What not to change

Keep Play Protect on

A Play Protect warning is a security decision. "Package conflicts", "invalid package" and "not compatible" are installation conditions. They are separate, and switching protection off fixes none of them.

Do not edit the APK

Renaming the extension, unpacking the file or rebuilding it with an editor changes the package. That turns a damaged-file problem into a signing conflict. Delete the failed download and get a fresh copy.
